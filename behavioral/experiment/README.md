# Experiment task code

Project files of the [Smile](https://smile.gureckislab.org) (v0.1.0) web app used for both studies
(Study 1 build). `design.js` is the timeline; `components/instructed_bandits_exp/bandits.js` defines
the eight bandit problems and their hints; `InstructedBandits.vue` is the game screen. To run: create a
Smile project, copy these files over `src/user/`, configure Firebase per the Smile docs.
